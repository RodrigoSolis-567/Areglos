# Arreglos

El programa es un menu para una tabla de datos de que contiene las ventas mensuales de diferentes areas de una tienda, este utiliza un arreglo para poder guardar la informacion de las ventas y otros 2 arreglos que contienen los meses y areas de la tienda.
estos utilizan un menu hecho con un switch(o match en python) para poder seleccionar cada opcion, estas son: visualizar la tabla de ventas, ingresar una venta, eliminar una venta, buscar una venta y finalizar el programa. Para esto el switch llama a cada metodo que tiene el programa. El metodo TablaDeVentas utiliza un printf para poder ingresar los datos de la tabla, empezando por el mes y el valor de cada area, y un for repite esta accion hasta llegar al mes 12 (diciembre). El metodo ingresar venta, por un print y un escaner te pregunta el numero del mes y del area, una vez compruebe por un if si estos datos no salen de los limites de 12 meses y 3 areas permite ingresar en el arreglo ventas para poder usarlo en la tabla. en el metodo eliminarVenta te pregunta nuevamente el numero del mes y del area, y si el if conprueba que no te sales de los limites de 12 y 3 meses, este remplazara el valor del dato del arreglo por 0. El metodo buscarVenta te pregunta otra vez el numero del mes y del area y si el if comprueba que no se salga del limite, un print arroja el dato de la celdseleccionada del arreglo, por ultimo la opcion de 5 de finalizar programa simplemente llama un break para cerrar el programa.

otro apartado que contiene es una opcion para reemplazar cada valor nulo del arreglo por un 0, asi evitando errores al momento de imprimir la tabla, usa un for para poder ingresar en cada valor de la tabla y colocar un 0 en su lugar cada que el programa se inicia
